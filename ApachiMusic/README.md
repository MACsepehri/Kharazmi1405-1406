## Apachi Music

A small open-source website to upload musics, add artists.
The tech that used for this website:

- Python (Flask framework)
- HTML / CSS / Javascript (Default)

## Running project

Run project.
in linux :
```bash
pip3 install -r requirements.txt
```
in windows :
```bash
pip install -r requirements.txt
```
Go and visit `.env` file and change some info :
```
ADMIN_USERNAME=your_admin_username
ADMIN_PASSWORD=your_admin_passowrd
SECRET_KEY=your_secret_key
```
Now you can run project easily!
in linux :
```bash
python3 app.py
```
in windows :
```bash
python app.py
```

Important tip : If you are using linux, use venv
